# 每日知識庫

🌐 網站：https://laura920069.github.io/daily-knowledge/
✏️ 管理後台：https://laura920069.github.io/daily-knowledge/admin/

每天由 Claude 排程自動整理 AI、投資理財（台股／ETF）、健身（增肌／減脂／柔軟度）、人資專業的知識，以 Obsidian 雙向連結組成知識網路，並推播到 LINE。

- `content/`：所有文章與概念卡（Markdown，可直接用 Obsidian 開啟）
- `GUIDE.md`：內容與來源規範（排程任務依此執行）
- `site-extra/admin/`：管理後台（Sveltia CMS）
- `site-extra/line/latest.json`：LINE 推播讀取的當日訊息
- 網站引擎：[Quartz 4](https://quartz.jzhao.xyz/)（MIT License，見 QUARTZ-LICENSE.txt）
